# Chain SDK documentation site

The public docs for developers building with Chain. How it's put
together, and what to update when Chain changes:
[`agent-docs/framework/site/README.md`](../agent-docs/framework/site/README.md).

From the repo root:

```bash
npm run docs         # dev server at http://localhost:3000
npm run docs:build   # static site in site/out/
```
